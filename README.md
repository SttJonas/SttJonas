## Featured project · Proyecto destacado

### [ServidorSTT](https://github.com/SttJonas/ServidorSTT)
Self-hosted web panel to import public repositories, review them and deploy apps with managed Docker profiles. / Panel web autoalojado para importar repositorios públicos, revisarlos y desplegar aplicaciones con perfiles administrados de Docker.

- **Architecture:** Node.js + Express panel, PHP + SQLite accounts service, Python host agent over a Unix socket.
- **Security design:** invitation-only accounts, hashed sessions, CSRF checks, CSP headers, the web container never mounts `docker.sock`, resource limits per container.
- **Stack:** JavaScript, Python, PHP, Docker, systemd.
